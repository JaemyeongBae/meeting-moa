# Security

Please do not put credentials, real meeting transcripts, recordings, or personal screenshots in public issues.

Report security problems through the repository's private vulnerability reporting feature when available. If it is unavailable, open a minimal issue asking for a private reporting channel without including exploit details or personal data.

This preview is not sandboxed or independently security-audited. Audio stays local during transcription, while AI summaries and questions send transcript text to the selected provider. See [data handling](docs/PRIVACY.md).
