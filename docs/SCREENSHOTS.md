# 미팅모아 화면

실행 중인 SwiftUI 앱을 직접 캡처했습니다. 모든 회의 내용과 역할은 `scripts/seed_demo.py`가 만든 **가상 데모 자료**입니다. 사용자 회의 저장소는 읽지 않았으며 개인 녹음이나 계정 식별자는 포함하지 않았습니다.
