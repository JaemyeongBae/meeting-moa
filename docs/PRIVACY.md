# 개인정보와 데이터 흐름

## 어디에 무엇이 저장되나요?

| 자료 | 처리·저장 위치 |
| --- | --- |
| 마이크 녹음 / 가져온 원본 복사본 | Mac의 `~/Library/Application Support/MoaMeeting/meetings/` |
| 발화자별 대화록, 회의록, 채팅 | 같은 폴더의 회의별 `meeting.json` |
| 음성 모델 | `~/Library/Application Support/MoaMeeting/models/` |
| Python 런타임 | `~/Library/Application Support/MoaMeeting/runtime/` |
| 작업 중 요청·진행 상태·로그 | `jobs/`의 임시 작업 폴더; 정상 완료·취소 처리 후 제거 |
| 문서용 가상 데이터 | 별도 `~/Library/Application Support/MoaMeetingDemo/` |

앱이 비정상 종료되면 임시 작업 파일이 남을 수 있습니다. 앱을 종료한 뒤 `jobs/`를 정리할 수 있습니다. `meetings/`에는 원본이 있으므로 임시 폴더와 혼동하지 마세요.

## 외부로 전송되는 것

- 음성 전사와 발화자 구분은 이 Mac에서 실행합니다.
- **회의록 생성·질문 시 대화록 텍스트와 필요한 채팅 맥락**이 선택한 공식 CLI를 통해 해당 AI 제공자에게 전송됩니다.
- 자동 요약은 기본 켜짐입니다. 앱 설정에서 끄면 로컬 전사 후 자동으로 AI 요청을 보내지 않습니다.
- 설치 시 모델과 패키지를 각 배포처에서 다운로드합니다.
- 앱 자체 분석·광고 추적 서비스는 없습니다. 공식 CLI의 네트워크·진단·보관 정책은 각 제공자와 사용자 설정에 따릅니다.

## 인증

로그인은 공식 CLI에서 합니다. 미팅모아는 토큰·비밀번호 입력란이나 자체 OAuth 로그인 서버를 제공하지 않습니다. 로그인 상태 확인에서 얻은 이메일·조직 정보는 UI에 표시하거나 회의 파일에 저장하지 않습니다.

## 로컬 보안

이 미리보기는 일반 데스크톱 앱이며 App Sandbox 배포판이 아닙니다. 회의 파일에 앱 자체 암호화는 적용하지 않습니다. 공유 Mac에서는 계정 분리와 운영체제 보호 설정을 고려하세요. API 키 등 민감한 값을 회의 제목이나 문서에 넣으면 텍스트로 저장·전송될 수 있습니다.

## 공개 저장소 원칙

실제 녹음, 실제 회의 JSON, 인증 파일, `.env`, 로그, 모델, Python 런타임, 빌드 결과는 커밋하지 않습니다. 스크린샷은 별도 데모 저장소의 가상 자료만 사용합니다. 개인 자료를 이슈·PR·스크린샷에 첨부하지 마세요. 재현 사례에는 합성 음성이나 익명화한 자료를 사용하세요.
