# 합성 음성과 데모 화면

## 샘플 녹음은 어떻게 만들었나요?

실제 회의를 녹음하지 않고 macOS의 기본 TTS인 `say`로 만들었습니다. `Yuna`와 `Eddy (한국어(한국))` 두 목소리로 가상의 회의 발언 네 개를 생성했습니다.

1. `say`로 각 발언을 AIFF 파일로 생성합니다.
2. FFmpeg로 16kHz·모노·16bit PCM WAV로 변환합니다.
3. 발언 사이에 1초 무음을 넣어 순서대로 연결합니다.
4. 완성된 약 38초 파일을 전사·발화자 구분 파이프라인에 넣습니다.

```bash
python3 scripts/make_fixture.py
```

필요한 macOS 목소리를 확인하려면 `say -v '?'`를 실행하세요. 목소리가 설치되어 있지 않은 Mac에서는 사용 가능한 이름으로 스크립트를 조정하거나 시스템 설정에서 음성을 준비해야 합니다.

기본 시스템 TTS라 억양이 기계적입니다. 16kHz 모노 변환도 고음질 감상용 설정은 아닙니다. 이 파일은 **두 목소리의 왕복 발언을 구분하는 기능 시험용**이며 실제 회의의 잡음·겹침·거리감을 대표하지 않습니다. 원본 스크립트의 “출시 날짜”를 전사 모델이 잘못 인식한 사례도 있어 전사와 요약 정확도를 보장하지 않습니다.

생성한 오디오 파일은 로컬 `artifacts/`에만 둡니다. 시스템 음성과 모델 자체를 이 저장소의 MIT 라이선스로 재배포하지 않습니다.

## 공개용 스크린샷

```bash
python3 scripts/seed_demo.py
./scripts/build.sh
open -n dist/미팅모아.app --args --demo --demo-home
```

`--demo`는 저장 경로를 별도 `MoaMeetingDemo`로 바꿉니다. `--demo-home`은 시작 화면부터 보여줍니다. 가상 회의, 수정된 예시 대화록, 요약, 질문 응답이 미리 채워집니다. 이는 **UI 설명용 고정 자료**이며 실시간 모델 출력이나 정확도 벤치마크를 가장하지 않습니다. 데모 시드에는 오디오가 포함되지 않으므로 원문 재생을 시험하려면 직접 만든 합성 녹음을 가져오세요.

개인 회의가 보이는 평소 실행 화면을 캡처해 공개하지 마세요. 업로드 전 이미지의 모든 문구와 메타데이터를 확인하세요.
