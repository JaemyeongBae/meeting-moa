# External components

MeetingMoa's MIT license covers original project code and documentation. Dependencies, downloaded models, system voices, and external services retain their respective licenses and terms. This repository does not redistribute their binaries or model weights.

| Component | Source / license information |
| --- | --- |
| whisper.cpp | [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp), MIT |
| Whisper weights | [OpenAI Whisper](https://github.com/openai/whisper), [converted weights](https://huggingface.co/ggerganov/whisper.cpp) |
| sherpa-onnx | [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), Apache-2.0 |
| Segmentation model | [sherpa converted models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-segmentation-models), [upstream model card](https://huggingface.co/pyannote/segmentation-3.0) |
| 3D-Speaker embedding model | [3D-Speaker](https://github.com/modelscope/3D-Speaker), [converted models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models) |
| FFmpeg | [FFmpeg licensing](https://ffmpeg.org/legal.html); the installed build's enabled components determine its license |
| NumPy / SoundFile / CFFI | Their installed package licenses; versions are pinned in `worker/requirements.txt` |
| Codex CLI | [openai/codex](https://github.com/openai/codex); OpenAI service terms apply to inference |
| Claude Code | [Claude Code legal conditions](https://code.claude.com/docs/en/legal-and-compliance); proprietary CLI installed separately |
| macOS system voices | Provided by Apple; used locally by the optional synthetic fixture generator, not included in this repository |

Review model cards and upstream licenses before redistributing model weights or packaging a standalone binary. The app icon is original vector artwork generated by `scripts/icon.swift` and is included under this project's MIT license.
